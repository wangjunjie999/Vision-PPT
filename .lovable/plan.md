# 远心相机支持

## 目标

管理员在硬件库添加相机时，先选择「普通相机 / 远心相机」。普通相机完全按原流程走；远心相机时，相关光学参数的名称改为远心语义：焦距 → 工作距离，光圈 → 放大倍率。光学方案图中的对应文字同步改变，其余信息不变。

## 数据存储（不做数据库迁移）

复用现有字段：用 `cameras.tags` 数组中的 `远心` 标记表示远心相机；镜头侧同样用 `lenses.tags` 中的 `远心` 标记。数值仍存在 `lenses.focal_length`（远心时含义为工作距离）与 `lenses.aperture`（远心时含义为放大倍率），只改变标签与展示文案，不新增数据库列。

## 界面改动

1. 管理后台 · 相机表单
   - 表单顶部新增「相机类型」单选：普通相机 / 远心相机，默认普通；新增时必须先选。
   - 保存时把 `远心` 写入或移除 tags，编辑时按 tags 回显。
   - 列表卡片对远心相机显示「远心」徽标。

2. 管理后台 · 镜头表单
   - 同样新增「镜头类型」单选。选远心时，字段标签实时切换为「工作距离」（示例 `如: 110mm`）与「放大倍率」（示例 `如: 0.5X`），字段键名不变，其余字段（品牌、型号、卡口、靶面尺寸、解析力）不变。
   - 列表规格行与硬件详情弹窗的标签按类型切换。

3. 光学方案图
   - 判定：当前模块选中的相机或镜头带 `远心` 标记。
   - 镜头卡片文字「焦距 25mm」改为「工作距离 25mm」；出现光圈的位置改为「放大倍率」。
   - HTML 预览与 SVG 导出两条渲染路径都同步修改。

4. 模块成像表单
   - 「光圈 (F值)」标签在远心时改为「放大倍率」，「推荐焦距」改为「推荐工作距离」。

5. PPT 输出
   - 工位幻灯片中「【镜头焦距/靶面】」标题与表头「焦距」在远心时改为「工作距离」。

## 技术实现

- 新增 `src/utils/telecentric.ts`：
  - `isTelecentricHardware(item)` 判断 tags 是否含 `远心`；
  - `getOpticalFieldLabels(isTelecentric)` 返回 `{ focalLabel, apertureLabel }`（普通：焦距 / 光圈；远心：工作距离 / 放大倍率）。
  - 所有展示点统一调用该工具，避免文案分散。
- `HardwareResourceManager` 的 `typeConfig` 字段列表改为按当前选中类型生成 label 与 placeholder。
- 不改动视场、成像等计算逻辑，也不改动其余字段。
