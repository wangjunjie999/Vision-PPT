# 机械布局与产品表单联动计划

## 1. 目标

让机械布局图与产品表单共享同一份产品数据，用户不再需要在“产品资产”和“布局对象”中重复维护名称、尺寸和位置。

核心体验：

1. 在表单中添加产品，画布立即出现对应产品。
2. 在画布中添加产品，表单立即出现对应产品卡片。
3. 任一侧修改名称、尺寸或坐标，另一侧自动更新。
4. 表单选中产品时，画布定位并打开该产品属性；画布选中产品时，表单高亮对应卡片。
5. 每个产品拥有独立尺寸、坐标、模型、图片和标注，主产品仅是业务标记，不再等同于唯一产品。

## 2. 现状与问题

原有实现存在两套独立数据：

- `product_assets`：维护产品名称、型号、素材和标注。
- `mechanical_layouts.layout_objects`：维护画布中的 `product` 图元和尺寸。

两者之间没有稳定主键映射，导致：

- 同一个产品可能拥有两个名称和两套尺寸。
- 表单新增/删除产品后，画布不会同步。
- 画布复制或删除产品可能产生“幽灵产品”或误删标注意图。
- 保存布局时只能保存图元快照，无法判断它对应哪条产品资产。

## 3. 目标数据模型

### 3.1 产品资产：业务主数据

`product_assets` 是产品的唯一数据源：

| 字段 | 用途 |
| --- | --- |
| `id` | 产品唯一标识 |
| `workstation_id` | 所属工位 |
| `product_name/code/spec` | 产品业务信息 |
| `length_mm/width_mm/height_mm` | 独立产品尺寸 |
| `pos_x/pos_y/pos_z` | 产品在工位坐标系中的位置 |
| `model_file_url/preview_images` | 产品视觉素材 |
| `sort_order/is_primary` | 排序和主产品标记 |

### 3.2 布局对象：渲染快照和布局关系

`LayoutObject` 中的产品对象新增 `productAssetId`，指向 `product_assets.id`。

布局对象继续保存以下快照，保证历史布局、离线缓存和报告导出兼容：

- `name`
- `productLength/productWidth/productHeight`
- `posX/posY/posZ`
- 挂载关系和旋转信息

读取时以产品资产为准，布局快照仅在资产字段为空或旧数据迁移时回落使用。

## 4. 联动流程

### 4.1 初始化

1. 加载当前工位 `mechanical_layouts.layout_objects`。
2. 加载当前工位所有 `scope_type = workstation` 的 `product_assets`。
3. 按 `productAssetId` 合并；旧布局没有关联 ID 时，按产品顺序进行一次兼容映射。
4. 数据库有产品但布局没有图元时，自动创建图元并按 Y 方向错开放置。
5. 已关联资产被删除时，从画布移除对应图元。

### 4.2 新增产品

- 从画布新增：先创建 `product_assets`，成功后再创建带稳定 ID 的布局对象。
- 从表单新增：创建产品资产并广播变更，画布自动生成对应图元。
- 第一个产品自动设为主产品，并继承工位默认 L/W/H。

### 4.3 编辑产品

- 表单编辑名称、L/W/H、X/Y/Z 后立即写入 `product_assets`，并刷新画布。
- 画布属性面板编辑名称或尺寸时，先更新本地图元，再以 450ms 防抖回写产品资产。
- 画布拖动结束或保存布局时，回写产品坐标，避免拖动过程中产生大量数据库请求。

### 4.4 选中与定位

- 表单点击产品卡片或“定位”，画布选中相应 `product-{assetId}` 并打开属性面板。
- 画布、对象列表或 3D 视图选中产品，表单高亮对应产品卡片。

### 4.5 删除

- 删除产品属于业务数据删除，可能级联删除素材和标注，必须从带确认框的产品管理入口执行。
- 画布中的快捷删除不会直接删除已关联产品，而是提示用户到右侧产品管理操作，避免误删。
- 未关联的历史图元仍可在画布直接删除。

### 4.6 保存与导出

- “暂存布局”和“保存全部视图”执行前，将所有已关联产品的名称、尺寸和坐标统一写回 `product_assets`。
- 保存后的 `layout_objects` 保留完整快照，报告生成逻辑无需立即重写。
- 后续报告层应优先读取 `product_assets`，布局快照作为历史兼容方案。

## 5. UI/UX 设计

### 5.1 机械布局步骤

新增“布局产品”卡片：

- 标题显示产品数量和双向同步说明。
- 绿色状态条说明产品资产是唯一数据源。
- 每个产品独立卡片展示序号、名称、主产品标记和定位按钮。
- 尺寸与坐标分为两个清晰区域，采用 L/W/H 和 X/Y/Z 工业参数表达。
- 空尺寸通过 placeholder 展示工位默认值，并在列表下说明回落规则。
- 无产品时显示单一主操作“添加第一个布局产品”。

### 5.2 画布工具栏

- “添加产品”按钮显示创建中状态。
- 同一行显示“n 个已关联产品”和链接状态，减少用户对保存范围的疑问。
- 产品尚在加载时禁用新增，避免重复提交。

### 5.3 属性面板

- 已关联产品显示“已关联右侧产品表单”标记。
- 每个产品继续拥有独立 L/W/H 编辑区。
- 已关联产品的删除动作引导到产品管理入口，避免误删素材和标注。

### 5.4 信息架构

- 产品名称、尺寸和位置归入“机械布局”步骤。
- 3D 模型、图片、检测要求和标注继续保留在“硬件/产品素材”区域。
- 后续可将第三步名称调整为“硬件与产品素材”，使导航语义更准确。

## 6. 分阶段实施

### 阶段 A：基础双向联动（本次已完成）

- 增加 `productAssetId`。
- 画布与产品资产加载合并。
- 双入口新增产品。
- 名称、尺寸、坐标双向同步。
- 表单到画布、画布到表单的选中联动。
- 保存前强制同步。
- 新增布局产品卡片、关联状态和加载状态。

### 阶段 B：数据一致性加固

- 提供一次性旧布局迁移脚本，将历史 product 图元正式写入 `product_assets`。
- 为产品尺寸增加数据库约束：尺寸为空或大于 0。
- 引入 `updated_at` 冲突检测，避免两个浏览器同时编辑时静默覆盖。
- 将自定义事件升级为统一产品 store/query cache，减少组件重复查询。
- 添加失败重试和“未同步”状态提示。

预计 1–2 个开发日。

### 阶段 C：高级布局能力

- 产品批量新增、复制和阵列排布。
- 产品间距、碰撞和越界提示。
- 产品版本/规格切换，支持同一工位的多规格方案。
- 主产品切换时同步更新工位默认尺寸策略。
- 报告、PDF、PPT 全部改为按产品资产输出多产品清单。

预计 2–4 个开发日。

## 7. 兼容与迁移策略

- 没有 `productAssetId` 的旧布局仍可打开和编辑。
- 当前工位有产品资产时，旧 product 图元按顺序与资产匹配。
- 当前工位没有产品资产时，保留原有默认产品图元，不在读取页面时自动写数据库。
- 用户首次显式新增产品后，产品资产成为该工位的主数据。
- 不删除旧的布局尺寸字段，确保历史截图和报告可重现。

## 8. 验收标准

### 功能

- 表单连续新增 3 个产品，画布出现 3 个独立产品，数量一致。
- 修改第 2 个产品 L/W/H，仅第 2 个产品外框和标签变化。
- 修改 X/Y/Z 或拖动画布，刷新页面后位置保持。
- 表单点击第 3 个产品，画布选中并打开第 3 个产品属性。
- 画布选择产品后，右侧对应卡片高亮。
- 删除产品后，画布对应图元消失，其他产品不受影响。
- 保存布局和生成截图后，多产品全部出现在 2D 与 3D 视图中。

### 质量

- TypeScript 类型检查通过。
- 现有 Vitest 测试通过。
- 右侧面板宽度 320px 时输入框和按钮不横向溢出。
- 新增/编辑失败时保留用户当前选择并显示明确错误。
- 快速连续拖动不会按鼠标移动频率写数据库。

## 9. 建议测试矩阵

| 场景 | 数据 | 重点 |
| --- | --- | --- |
| 新工位 | 无产品、无布局 | 空状态与首次新增 |
| 老工位 | 有旧 product 图元、无资产 | 兼容展示 |
| 混合工位 | 有旧图元、有产品资产 | 顺序映射与稳定 ID |
| 多产品 | 1/3/10 个产品 | 自动缩放、性能和卡片滚动 |
| 异常网络 | 保存超时/失败 | 本地状态、错误反馈、重试 |
| 多视图 | 正/侧/俯/等轴 | 尺寸与位置一致性 |
| 挂载机构 | 产品挂载并移动机构 | 产品坐标回写 |
